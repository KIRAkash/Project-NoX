# Market Data Gateway (MDG)

Part of the Global Financial Markets Group (GFMG) - Nexus Trading Exchange (NTE) platform.
Owner: Apex GitHub Org (`@apex/market-data-team`)

## Overview
The Market Data Gateway acts as the primary egress point for all public-facing market data. It consumes internal message streams (Kafka) generated by the `order-matching-engine` and broadcasts them via ultra-low latency WebSockets to external participants.

### Dependencies
- `order-matching-engine` (Produces `nte.orderbook.snapshots` and `nte.trades.matched`)
- `compliance-surveillance-monitor` (Consumes our telemetry via `nte.mdg.telemetry`)
- `trade-settlement-system` (Provides end-of-day reference data)

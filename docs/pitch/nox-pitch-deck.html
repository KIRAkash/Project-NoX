14 Trust by design Enterprise-ready
NX

Grounded, scoped, and always a person’s call.

☺
People own decisions

Agents draft, look up and check. Only people approve, verify or send back.

⌘
Grounded or it doesn’t ship

Every claim cites a KB page, a spec file, a path:line or a Jira field.

◎
Scope set by NoX, not the model

Tools read access from session state. No prompt can widen what an agent sees.

①
One human per file

Each spec file has one editing seat. Others read it locked. No merge fights.

⎇
Yours, in Git

Knowledge and specs are open-format files in repositories you own and review.

⛨
Checked before commit

Linter, secret gate and PR guard stand between model output and your repos.
